# Zomato Dataset

The raw Zomato CSV files used by this project are intentionally excluded
from GitHub because the dataset is approximately 2.45 GB.

Expected files:

- food.csv
- menu.csv
- orders.csv
- order_items.csv
- restaurant.csv
- reviews.csv
- users.csv

The pipeline expects these files locally before uploading the raw data
to AWS S3.

Raw data is not committed to this repository.
